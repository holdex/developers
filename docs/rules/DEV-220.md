## Problem

An issue or PR URL pasted inline in a sentence does not expand to its title and
is easily lost in prose. Readers cannot see at a glance what is referenced.

## Solution

Reference issues and pull requests as list items, so GitHub expands each to show
its title.

```md
See these related items:

- <issue_or_pr_url>
- #4
- #12
```

Do not paste references inline in a sentence.

### Acceptance Criteria

- [ ] Issue and PR references are list items, not inline in prose
- [ ] Each reference sits on its own line
