## Problem

A PR opened late, left unlinked or unassigned, or marked ready before CI and
review, produces untracked, unreviewable work that stalls or merges unchecked.

## Solution

Follow these steps in order, from start to submission.

1. Open a draft PR as soon as you start work on a Problem.
1. Link the PR to its Problem issue using a closing keyword.
1. Assign yourself, so it is clear who owns it.
1. Report time, opening the PR early so tracking includes investigation.
1. Assign at least one reviewer.
1. Include a preview link when the change is visually verifiable.
1. Mark ready for review only once every step above is done.
1. Resolve all CI checks; CI runs after marking ready, so do not request
   approval until it passes.

Do not merge without an approved review and passing CI checks.

### Acceptance Criteria

- [ ] A draft PR is opened at the start and linked to its Problem with a closing
  keyword
- [ ] The PR is self-assigned, has at least one reviewer, and a preview link
  where applicable
- [ ] It is marked ready only after the above, with CI passing
- [ ] It is not merged without an approved review and passing CI
