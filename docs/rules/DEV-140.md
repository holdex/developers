## Problem

A Goal with assignees but no ETA leaves stakeholders unable to plan around it.
An ETA guessed before the goal is understood is fiction, and misleads worse than
none.

## Solution

Commit an ETA on the Goal, but only once you understand it.

1. Set the ETA only after the Spec is clear and agreed, per
   [DEV-130](./DEV-130.md).
1. Record it in the Goal's `# Deadline` section, per [DEV-120](./DEV-120.md),
   using the [Wizard commands](https://wizard.holdex.io/docs/commands). Use
   `ETA: undefined` when no date is known yet.

### Acceptance Criteria

- [ ] The Goal carries an `ETA:` line while it has assignees
- [ ] The ETA was set only after the goal was understood and agreed
- [ ] It is recorded through the documented
  [Wizard commands](https://wizard.holdex.io/docs/commands)
