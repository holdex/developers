## Problem

A Solution delivered outside a pull request bypasses review, time tracking, and
the PR requirements. There is no record of who resolved the Problem, or whether
the work met the guidelines.

## Solution

Present every Solution, whether code, design, or marketing material, as a pull
request.

1. Open the PR against the Problem it resolves and link that Problem issue.
1. Keep the work lean and clean, scoped to the Problem.
1. Comply with the PR requirements
   ([PR Requirements](../CONTRIBUTING.md#pr-requirements)) before requesting
   review.

For reimbursable work-related costs, see [Expenses](../EXPENSES.md).

### Acceptance Criteria

- [ ] The Solution is delivered as a pull request
- [ ] The PR links the Problem issue it resolves
- [ ] The PR meets the PR requirements before review is requested
