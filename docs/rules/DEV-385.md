## Problem

A function kept private to its module cannot be tested on its own, so an agent's
mistake in it surfaces only through a whole feature, or in production. Tests
that run only in CI reach the author after the commit is pushed.

## Solution

Make every function reachable by a test, cover it, and run the tests where the
author sees the failure first.

1. Export every function from its module, so a test can import and call it
   directly.
1. Cover each function with a unit test in the same PR that adds or changes it,
   including its edge cases.
1. Run the tests in the `pre-commit` hook of the repository's `lefthook.yml`,
   the same hook that runs lint per [DEV-380](./DEV-380.md), so a failing test
   blocks the commit locally.
1. Run the same tests in CI on every pull request, so a commit that skipped the
   hook still cannot merge.

### Acceptance Criteria

- [ ] Every function is exported from its module
- [ ] Every function added or changed in a PR has a unit test in that PR
- [ ] The `pre-commit` hook runs the tests and blocks a commit that fails them
- [ ] CI runs the same tests and fails a pull request that breaks them
