## Problem

When work in progress goes quiet, nobody can tell whether it is moving, stalled
or waiting on someone, so blockers surface days late.

## Solution

An update is how the team sees work without asking about it. One short note a
day on the item you own replaces the status question, and a blocker named on the
day it appears can be cleared that day.

1. On each working day you work on a Problem or PR assigned to you, leave one
   update on it.
1. Post it on the Problem issue or the PR, never on the Goal, per
   [DEV-210](./DEV-210.md).
1. Say what moved since the last update, what comes next, and what blocks it.
   Mention the person who can unblock it.
1. Keep it to the point, per [DEV-230](./DEV-230.md). When nothing moved, say so
   and why.

```md
Good: Approver picker done and pushed. Next: rejection flow. Blocked on
      which fields MAS receives, @owner.
Bad:  Still working on it.
```

### Acceptance Criteria

- [ ] Every Problem or PR worked on that day carries an update from its owner
- [ ] Updates sit on the Problem or PR, not the Goal
- [ ] Each update states progress, the next step, and any blocker with who can
      clear it
