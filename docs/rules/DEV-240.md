## Problem

An @mention used to thank or acknowledge sends a notification that asks nothing,
so people learn to skim their mentions and miss the ones that need them.

## Solution

A mention is a request for someone's attention. Spend it only when you need
something from them, so every mention they receive is worth opening.

1. Mention a person when they need to act: answer, decide, review or unblock.
   Say in the same message what you need, per [DEV-230](./DEV-230.md).
1. Acknowledge with a reaction, not a comment that mentions them.
1. A reaction acknowledges a notice. It does not answer a question, because it
   does not say which way you decided. A question addressed to you gets a
   written reply.

```md
Good: @reviewer, the approver rule is in. Can you confirm it matches the tables?
Bad:  Thanks @reviewer!
```

### Acceptance Criteria

- [ ] Every mention asks the person mentioned to do something
- [ ] Acknowledgment is given with a reaction, not a mention
- [ ] No question addressed to you is answered with a reaction alone
