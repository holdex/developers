## Problem

Waiting for a second developer to review stalls a PR for hours or days, while
agents review in minutes, at any hour, and catch more bugs and edge cases than a
human pass does.

## Solution

Agent review is the review gate before merge. Agents do not sleep, eat, or miss
a notification, so the review happens while the change is still fresh. The agent
is a tool: the developer runs the review, merges the PR, and stays responsible
for every PR their agents produce and for what it does in production.

1. Run agent review on every PR before merge, more than once, with more than one
   model.
1. Fix each finding and run the review again. When a finding is wrong, answer it
   in the PR instead of changing the code.
1. Merge the PR yourself once agent review comes back clean and CI passes. A
   second developer's approval is not required, except in the two cases below.
1. Get approval from another member before merging a PR that changes
   authentication, permissions, secrets, payment flows, or access to sensitive
   data. Any other developer, lead, or partner can approve. The approval is on
   whether the change is safe to run in production, not on code quality, which
   agent review covers.
1. Get review from the people who will work from a Spec PR, or take part in it,
   before merging it. Their review is feedback on the ideas: the business logic,
   the scope, and what to build, per [DEV-130](./DEV-130.md). A Spec that only
   its author will implement merges on agent review.
1. When a human does review, [DEV-410](./DEV-410.md) and [DEV-415](./DEV-415.md)
   apply as before.

### Acceptance Criteria

- [ ] Every PR has agent review before merge, repeated, with more than one model
- [ ] Each finding is fixed or answered in the PR
- [ ] The developer who opened the PR merges it and owns the result
- [ ] A PR touching authentication, permissions, secrets, payments, or sensitive
      data has another member's approval before merge
- [ ] A Spec PR that others work from or take part in is reviewed by them before
      merge
