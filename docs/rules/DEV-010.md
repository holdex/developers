## Problem

A rule that bundles several behaviors, or one behavior spread across several
files, cannot be checked or referenced cleanly. A reviewer cannot say whether a
subject passes it, and other rules cannot depend on a precise, single thing.

## Solution

A rule is only enforceable if it makes one claim you can check. Bundle two and a
reviewer can pass half and fail half with no clear verdict, and no other rule
can depend on a precise, single thing. So scope each file to one behavior. Two
quick tests: if the title needs "and" to join unrelated behaviors, split it; if
one behavior only makes sense beside another, keep them apart and couple them
through `depends_on` rather than merging.

### Acceptance Criteria

- [ ] The rule describes exactly one behavior
- [ ] The behavior can be checked pass or fail against a single subject
- [ ] No unrelated behavior shares the file
