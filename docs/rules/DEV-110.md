## Work From a Goal Issue

### Problem

Work started without a Goal has no business aim, no Spec to work against, and no
ETA. Effort is unanchored, and no one can tell what it is meant to achieve or
when.

### Solution

Start every contribution from a Goal issue.

1. Find a Goal by filtering the relevant repo's issues for the `Goal:` prefix.
   Prioritize by impact and urgency; consult your lead if unsure which to take.
1. Assign yourself to the Goal issue.
1. Review the linked Spec and assess the outstanding Problems.
1. Provide an estimated time of achieving (ETA). Set it with
   `@holdex issue set-eta`.

A Goal follows the pattern `Goal: [statement]` and must link a Spec with an ETA.

#### Acceptance Criteria

- [ ] The work traces to a `Goal:` issue
- [ ] You are assigned to that Goal
- [ ] The Goal links a Spec and carries an ETA
